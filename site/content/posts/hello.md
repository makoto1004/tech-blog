POS レジのヘルプデスクの仕事をしながら、社内SE・クラウド運用を目指して AWS を練習しています。このブログには、練習で作った構成と、わざと起こした障害の記録を置いていきます。

## このブログの作り

| 部品 | 役割 |
| --- | --- |
| Hugo | Markdown で書いた記事を、ページ（HTML）に変える |
| S3 | ページの置き場。外からは直接見られないようにしている |
| CloudFront | ページを https で配る。S3 を読めるのは CloudFront だけ（OAC） |
| Terraform | S3 と CloudFront をコードで作る。state も S3 に置いている |
